# Data Cleaning, Preparation & Exploratory Analysis

Course: ws_04  
Level: Beginner to intermediate  
Duration: 26 lessons

## Learning outcomes
Inspect datasets; identify and document quality issues; clean and transform data with Python and Pandas; validate joins and derived fields; perform descriptive and exploratory analysis; create honest visualisations; and communicate reproducible findings with limitations.

## Course sequence
01. Data Cleaning and EDA: The Big Picture
02. Rows, Columns and Observations
03. Data Types and Measurement Scales
04. Importing CSV and Excel Files
05. First Inspection with Pandas
06. Data Quality Dimensions and Profiling
07. Missing Values: Detection and Meaning
08. Handling Missing Values Responsibly
09. Duplicate Records and Entity Keys
10. Cleaning Text and Standardising Categories
11. Converting Numeric Fields Safely
12. Dates, Times and Chronological Data
13. Outliers: Detection versus Error
14. Validation Rules and Impossible Values
15. Consistent Units and Currency
16. String Parsing and Structured Fields
17. Filtering, Sorting and Selecting Records
18. Transformations and Derived Columns
19. Joining Tables and Checking Relationships
20. Descriptive Statistics for Cleaned Data
21. Distributions, Skewness and Percentiles
22. Univariate EDA: One Variable
23. Bivariate EDA: Relationships
24. Multivariate EDA and Segmentation
25. Visualisation Choices and Honest Charts
26. Reproducible Cleaning Pipeline
27. End-to-End Cleaning and EDA Project

Each lesson includes a learning goal, plain-language explanation, practical example, Python/Pandas exercise, common mistakes, assignment, deliverables and self-check. Final project: reproducible notebook/script, cleaned dataset, quality log, four charts, five findings, three recommendations and limitations.

Recommended tools: Python 3, Jupyter Notebook or Google Colab, Pandas, Matplotlib, CSV/Excel files.
