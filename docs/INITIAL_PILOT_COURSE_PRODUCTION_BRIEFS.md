# Learnora ME — initial pilot course production briefs

**Status:** Draft course briefs for internal review and Course Studio entry. These are not live course records and do not authorise publication.

## Catalogue structure

Preserve the hierarchy:

- **Track:** groups related courses in a learning pathway.
- **Course:** can stand alone or be linked to one or more tracks.
- **Module:** a section within one course.
- **Lesson:** a focused learning unit, normally 1–3 minutes and never more than 5 minutes.

Initial catalogue:

| Track | Course | Relationship |
|---|---|---|
| Data Analytics | Data Analytics | Core course in the Data Analytics track |
| Data Analytics | Excel Fundamentals | Standalone course that can also be included in the Data Analytics track |
| Front-end Web Development | Front-end Web Development | Core course in the Front-end Web Development track |

The Data Analytics course includes an Excel-for-analysis module. Excel Fundamentals is a separate, deeper course. The Data Analytics module should teach Excel as an analytics tool; it should not duplicate the full Excel Fundamentals curriculum.

## Production order

1. **Data Analytics** — priority for the upcoming WitStart learner pilot.
2. **Excel Fundamentals** — a separate standalone course that can be offered alongside Data Analytics.
3. **Front-end Web Development** — a separate track and course.

Generate and review one course at a time. Keep every course unpublished until its lesson packages, media, assessments, track relationship and learner journey have been checked.

## Course 1 — Data Analytics

**Track:** Data Analytics  
**Level:** Beginner  
**Target audience:** Learners new to data analytics who can use a computer and want to develop practical skills for working with data. No prior programming or analytics experience is required.  
**Prerequisites:** Basic computer literacy; willingness to practise with spreadsheets.  
**Course description:** A practical introduction to the data analytics process, from understanding data and asking useful questions to cleaning, analysing and communicating findings with spreadsheets, SQL, Python and a visualisation tool.

### Learning outcomes

By the end, learners should be able to:

- Explain what data analytics is and distinguish it from related terms.
- Identify common data types and recognise data-quality problems.
- Describe the stages of a practical analytics workflow.
- Use Excel to organise, clean, analyse and summarise a dataset.
- Write introductory SQL queries to retrieve and aggregate data.
- Use Python for basic data inspection and analysis.
- Build and interpret clear charts and a simple dashboard.
- Explain findings and make evidence-based recommendations.

### Course outline

Module 1: Introduction to Data Analytics
- What is data analytics?
- Data analytics, data analysis and data science
- Careers and roles in data analytics
- Why organisations use data analytics

Module 2: Understanding Data
- What is data?
- Structured and unstructured data
- Qualitative and quantitative data
- Common data types and measurement scales

Module 3: The Data Analytics Process
- From a business question to an analytical question
- Collecting and understanding data
- Preparing and analysing data
- Interpreting and communicating findings

Module 4: Excel for Data Analytics
- Understanding workbooks, worksheets, rows and columns
- Entering and formatting analytical data
- Sorting and filtering records
- Essential formulas and cell references
- Using common functions to summarise data

Module 5: Data Cleaning and Preparation
- Why data quality matters
- Identifying missing and duplicate records
- Correcting inconsistent values and formats
- Working with dates, text and categories
- Checking a dataset before analysis

Module 6: Introduction to SQL
- What a database table represents
- Selecting columns and limiting results
- Filtering records with WHERE
- Sorting and grouping records
- Aggregating data with COUNT, SUM and AVG

Module 7: Python for Data Analysis
- What Python contributes to analytics
- Working with notebooks and scripts
- Loading a dataset with Pandas
- Inspecting columns, types and missing values
- Filtering, grouping and summarising data

Module 8: Data Visualisation
- Why visualisation matters
- Choosing a suitable chart
- Building clear charts from analytical results
- Understanding filters, measures and dimensions
- Creating a simple dashboard

Module 9: Communicating Insights
- Turning analysis into a clear finding
- Separating evidence from assumptions
- Explaining trends and comparisons
- Making practical recommendations

Module 10: Guided Analytics Project
- Understanding the project question and dataset
- Preparing and analysing the dataset
- Presenting findings and recommendations

**Course production note:** Keep the Excel module focused on the spreadsheet skills needed for an analytics workflow. The separate Excel Fundamentals course covers broader spreadsheet proficiency in more depth. Use small, realistic datasets and worked examples. Any software demonstration must use the actual interface/version available to the production team; do not fabricate software screens or outputs.

## Course 2 — Excel Fundamentals

**Track:** Data Analytics (optional membership; the course remains independently available)  
**Level:** Beginner  
**Target audience:** Students, job seekers and working professionals who want to use Microsoft Excel confidently for everyday data organisation, calculations, reporting and analysis.  
**Prerequisites:** Basic computer literacy.  
**Course description:** A hands-on introduction to Excel, covering workbook navigation, data entry, formatting, formulas, functions, data organisation, charts and a practical reporting task.

### Learning outcomes

By the end, learners should be able to:

- Navigate workbooks and worksheets.
- Enter, format and organise data consistently.
- Use formulas, cell references and common functions.
- Sort, filter and validate spreadsheet data.
- Use lookup functions to combine information.
- Summarise data with tables and PivotTables.
- Create charts and a clear spreadsheet report.

### Course outline

Module 1: Getting Started with Excel
- What Excel is used for
- Workbooks, worksheets, rows, columns and cells
- Navigating the Excel interface
- Creating, saving and organising a workbook

Module 2: Entering and Formatting Data
- Entering and editing cell values
- Number, date and text formats
- Adjusting columns, rows and worksheet layout
- Applying readable cell formatting

Module 3: Formulas and Cell References
- Writing a basic formula
- Arithmetic operators and order of operations
- Relative and absolute cell references
- Copying formulas safely

Module 4: Essential Excel Functions
- Using SUM, AVERAGE, MIN and MAX
- Counting values with COUNT and COUNTA
- Conditional logic with IF
- Conditional counting and summing with COUNTIF and SUMIF

Module 5: Organising and Cleaning Data
- Sorting records
- Filtering a dataset
- Removing duplicates
- Finding and correcting inconsistent entries
- Using data validation

Module 6: Lookup and Reference Functions
- Why lookups are useful
- Using XLOOKUP where supported
- Understanding VLOOKUP in existing workbooks
- Handling missing lookup results
- Combining information from separate tables

Module 7: Tables, PivotTables and Charts
- Converting a range into an Excel Table
- Summarising data with a PivotTable
- Grouping and filtering a PivotTable
- Choosing and formatting a suitable chart

Module 8: Practical Spreadsheet Report
- Understanding a reporting task
- Preparing a small source dataset
- Building calculations and summaries
- Presenting a clear one-page report

**Course production note:** Check function availability against the Excel version used in each demonstration. If a function is not available in older versions, explain the supported alternative. Do not invent formula results; show a real workbook or verified sample output.

## Course 3 — Front-end Web Development

**Track:** Front-end Web Development  
**Level:** Beginner  
**Target audience:** Beginners who want to build websites and interactive browser-based interfaces. No previous programming experience is required.  
**Prerequisites:** Basic computer literacy and access to a modern web browser and code editor.  
**Course description:** A practical introduction to building websites with HTML, CSS and JavaScript, progressing from page structure and styling to responsive layouts, browser interaction, APIs and a complete front-end project.

### Learning outcomes

By the end, learners should be able to:

- Explain how a browser loads and displays a web page.
- Structure accessible pages with HTML.
- Style layouts and components with CSS.
- Build responsive interfaces for different screen sizes.
- Write JavaScript to add interaction.
- Work with the DOM, events and browser APIs.
- Retrieve and display data from a web API.
- Use Git and GitHub for basic version control.
- Build and publish a small front-end project.

### Course outline

Module 1: How the Web Works
- What happens when a website is opened
- Websites, web pages, browsers and servers
- The roles of HTML, CSS and JavaScript
- Setting up a code editor and project folder

Module 2: HTML Foundations
- HTML document structure
- Headings, paragraphs and text elements
- Links, images and file paths
- Lists and tables
- Semantic page structure

Module 3: Forms and Accessible HTML
- Building a form
- Labels and input types
- Buttons and form submission
- Semantic landmarks and accessible names

Module 4: CSS Foundations
- Connecting CSS to HTML
- Selectors and declarations
- Colours, typography and spacing
- The box model
- Reusable classes and component styling

Module 5: Layout and Responsive Design
- Normal document flow
- Flexbox layouts
- CSS Grid layouts
- Media queries and responsive breakpoints
- Testing layouts on mobile and desktop

Module 6: JavaScript Foundations
- Values, variables and data types
- Operators and expressions
- Conditions and loops
- Functions and parameters
- Arrays and objects

Module 7: JavaScript in the Browser
- Understanding the DOM
- Selecting and updating elements
- Handling user events
- Validating form input
- Managing simple interface state

Module 8: Working with Data and APIs
- What an API is
- HTTP requests and JSON
- Fetching data with JavaScript
- Loading, success and error states
- Displaying API data in a page

Module 9: Git, GitHub and Publishing
- Why version control matters
- Initialising and committing a project
- Creating and updating a GitHub repository
- Understanding branches and basic collaboration
- Publishing a static front-end website

Module 10: Front-end Project
- Planning a small website
- Building the HTML structure
- Styling responsive layouts
- Adding JavaScript interaction
- Testing, correcting and publishing the project

**Course production note:** Use real code-editor demonstrations and verify every code sample and browser result. Do not create fake terminal output or screenshots. Break larger builds into small observable steps so each lesson teaches one manageable idea.
